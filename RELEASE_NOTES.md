# RENSA 1.0.0 — FIRST FROZEN RELEASE

**Release line:** 1.0.x  
**Status:** FROZEN BASELINE  
**Target:** GitHub Pages / mobile PWA  

## Included

- Severe AMOLED mobile UI.
- Installable/offline Progressive Web App.
- Full 50-minute weekly session engine.
- Compact 20-minute mode and 5-minute QA preview.
- Audio transition tones and Speech Synthesis cues.
- Screen Wake Lock request where browser support exists.
- Technique library with functional classification and honest solo-representation labels.
- 16-term technical glossary spanning hybrid, judo, wrestling, FMA and RENSA-specific vocabulary.
- 9-stage dependency-ordered curriculum (explicitly not a belt/mastery ladder).
- Initial striking corpus: 1–2, 1–1–2, 1–2–3, 1–2–3–2.
- Seven retained takedown families with solo shadow-entry rules.
- Hubud-Lubud open-hand solo proxy.
- Standing Ezekiel and RNC position-recall entries with compression excluded.
- Eight cross-domain training chains.
- P1–P8 pressure-retrieval ladder.
- Optional resistance-band overlays.
- Persistent local ledger.
- JSON export/import.
- Default 72 × 24 inch / quiet / solo environment profile.

## Deliberately excluded from 1.0

- Partner/live-resistance tracking.
- Video library hosting.
- Cloud sync or accounts.
- Scoring “mastery” percentages.
- Ground locomotion requiring more floor width.
- Breakfalls or impact throwing.
- Weapon curriculum.
- Sensors, camera pose estimation, Apple Health integration.

## Known platform limitation

Mobile operating systems can throttle/suspend browser timers and speech when a PWA is backgrounded or the device locks. RENSA requests a screen wake lock when supported, but the most reliable guided-session behavior is with the PWA visible in the foreground.
